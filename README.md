# 🙋 My Profile

เว็บไซต์แนะนำตัวเอง สร้างด้วย HTML และ CSS

## 👤 เกี่ยวกับฉัน

- **ชื่อ:** นายเจตนิพิฐ จันทร์วิลัย
- **อายุ:** 20 ปี
- **การศึกษา:** วิทยาลัยเทคนิคสมุทรปราการ
- **สิ่งที่สนใจ:** เขียนโปรแกรม, พัฒนาเว็บไซต์

## 📁 ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|------|---------|
| `index.html` | โครงสร้างและเนื้อหาของหน้าเว็บ |
| `style.css` | ตกแต่งหน้าเว็บ |
| `README.md` | อธิบายโปรเจกต์ |

## 🚀 วิธีดู

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย
